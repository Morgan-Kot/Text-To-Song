THE ALGORITHM
─────────────
Every character converts to a musical note using:
  semitone = ASCII code % 12
  octave = base_octave + (ASCII code / 12) % range

This means EVERY character always maps to the SAME note, every time.


THE 12 CHROMATIC NOTES (repeating cycle)
─────────────────────────────────────────
A  A#  B  C  C#  D  D#  E  F  F#  G  G#  [repeat]


SPECIAL CHARACTERS
──────────────────
SPACE        = REST (silence)
TAB          = REST (silence)  
NEWLINE      = SHORT REST (quarter pause)

EXAMPLES
────────

"Hello"
→ H=A, e=F, l=A, l=A, o=C
→ MELODY: A-F-A-A-C

"Music"
→ M=F, u=A, s=G, i=A, c=C
→ MELODY: F-A-G-A-C

"Code"
→ C=G, o=C, d=D, e=F
→ MELODY: G-C-D-F

"Hi World"  (with space)
→ H=A, i=A, [SPACE]=REST, W=C, o=C, r=F#, l=A, d=D
→ MELODY: A-A-[REST]-C-C-F#-A-D

"123"
→ 1=C#, 2=D, 3=D#
→ MELODY: C#-D-D# (chromatic ascending!)

"Song!"
→ S=G#, o=C, n=B, g=G, !=A
→ MELODY: G#-C-B-G-A


TIPS FOR GREAT MELODIES
───────────────────────
• Uppercase vs Lowercase: Same letter, ~1 octave apart. Mix for range!
• Use SPACES to create pauses between phrases
• Add punctuation (!, ?, .) for surprise notes
• Type "0123456789" for a chromatic run (C#-D-D#-E-F-F#-G-G#-A-A#)
• Fast tempo (50 ms) = zippy; Slow (400+ ms) = majestic
• Sine = pure tone; Triangle = flute; Sawtooth = bright/buzzy
• Repeat words for musical motifs
• Octave range 1 = tight register; 3+ = wide & sweeping


QUICK FORMULA REFERENCE
───────────────────────
For any character, to find its note in octave 3:
  1. Get ASCII code: ord(char)
  2. semitone_index = ASCII % 12
  3. Look up NOTE_NAMES[semitone_index]

Example: Letter 'M'
  ord('M') = 77
  77 % 12 = 5
  NOTE_NAMES[5] = 'D'
  Then octave is calculated separately based on range
