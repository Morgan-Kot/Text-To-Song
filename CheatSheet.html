Every letter, digit, and symbol becomes a unique musical note based on its ASCII code

The Algorithm

Every character is converted to a musical note using a simple formula:

semitone = ASCII % 12
octave = base + (ASCII ÷ 12) % range

This ensures every character always maps to the same note.

12 Chromatic Notes

All notes repeat in a cycle of 12:

A A# B C C# D
D# E F F# G G#

Special Characters

Space = Rest (silence)

Tab = Rest (silence)

Newline = Short Rest

💡 Tips for Creating Melodies

  • Uppercase vs Lowercase: Same letters produce notes ~12 semitones apart (one octave higher for lowercase). Mix them for range!
  • Spacing: Use spaces and newlines to create rhythmic pauses. Group words for musical phrases.
  • Punctuation: Add ! ? . , and other symbols to insert unexpected notes and spice up melodies.
  • Numbers: 0-9 produce a sequence of 12 semitones. Try "0123456789" for a chromatic run!
  • Repetition: Type the same word twice to create a musical motif that repeats.
  • Tempo: Fast (50 ms) creates zippy arpeggios; slow (400+ ms) creates majestic hymns.
  • Waveform: Sine = smooth; Triangle = flute-like; Sawtooth = bright and buzzy.
  • Octave Range: Try range=1 for mono-register harmonies, or range=3+ for wide, sweeping melodies.
